# Retail Sales Analytics & Revenue Optimization

A comprehensive data analysis project examining **73,000 retail transaction records** spanning across 2023 and 2024. This project extracts key performance metrics, regional sales trends, brand performance, and customer purchasing behaviors using Python's data analysis stack.

## Dataset Overview

The dataset contains 19 descriptive attributes tracking end-to-end retail sales and store operations:

| Feature Category | Features Included |
| :--- | :--- |
| **Temporal Data** | `Date`, `Holiday_Flag` |
| **Store Metadata** | `Store_ID`, `Store_Location`, `Region`, `Store_Rating` |
| **Product Attributes** | `Product_ID`, `Product_Category`, `Product_Subcategory`, `Brand` |
| **Financial Metrics** | `Unit_Price`, `Units_Sold`, `Total_Sales`, `Discount_Percentage`, `Revenue` |
| **Customer & Operations**| `Customer_Type`, `Payment_Mode`, `Promotion_Applied`, `Stock_On_Hand` |
